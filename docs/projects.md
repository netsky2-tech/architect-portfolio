## 1. AINativeNav: AI-Powered Geocoding

- Descripción del Problema: Solución al sistema de direcciones por referencia de Nicaragua mediante el uso de LLMs para traducción a coordenadas geográficas.
- Arquitectura: Implementación de orquestación de contexto modular para procesar lenguaje natural semántico.
- Stack Tecnológico: React 19, PostgreSQL, Docker, y AI Skills Orchestration.
- Impacto Clave: Automatización del mapeo de rutas críticas y reducción de errores en la navegación nativa.

## 2. Modernización: Nuevo Hospital Monte España

- Descripción del Proyecto: Migración integral del sistema de admisión hospitalaria hacia una arquitectura moderna.
- Hito Técnico: Transición exitosa a .NET Core 8, eliminando cuellos de botella en la base de datos SQL Server.
- Stack Tecnológico: .NET Core 8, C#, Entity Framework y SQL Server.
- Métrica de Impacto: Incremento del 25% en la velocidad de procesamiento de pacientes y reportes administrativos en tiempo real.

## 3. SaaS Smart Agenda: Offline-First Architecture

- Descripción del Proyecto: Sistema de gestión de citas y agendas para profesionales con nichos dinámicos según el rubro del negocio.
- Diferenciador Técnico: Diseño de arquitectura Offline-first utilizando DexieDB para persistencia en el navegador.
- Stack Tecnológico: Laravel 12, React 19, Zustand y DexieDB.
- Métrica de Eficiencia: Sincronización de datos con latencia cero y reducción del 40% en el tiempo de desarrollo mediante metodología AIDD.
