# Prompt

```text
Actúa como un Senior UI/UX Designer especializado en productos para desarrolladores y arquitectos de software.
Objetivo: Diseñar la interfaz de un portafolio web para Octavio Morales, un Senior Software Engineer y AI Architect. El diseño debe alejarse de los bento-grids tradicionales y las landing pages de "SaaS azul" comunes. Debe sentirse como una herramienta de ingeniería de alto nivel, profesional pero con una estética "Cyber-Brutalista" refinada.
Concepto Visual: "Modular Context Orchestration"
Identidad Visual: La web debe simular un entorno de desarrollo (IDE) moderno pero elevado a diseño artístico. Usa una paleta de "Modo Oscuro Profundo" (Carbon #0D1117) con acentos en verde terminal (#00FF41) y azul cobalto para representar la robustez de .NET.
Texturas: Usa fondos con sutiles rejillas de puntos (dot grids), líneas de conexión que parezcan diagramas de arquitectura hexagonal y desenfoques (glassmorphism) muy ligeros para separar capas.
Secciones Obligatorias con Estilo Único:
The Master Header: No es un banner, es un "Header de Sistema". Incluye el nombre "Octavio Morales" en una tipografía monoespaciada premium. A la derecha, un indicador de "Estado de Sistema" que diga: Status: Online | Location: Managua, NI | Latency: 0ms.
Hero "The AI Orchestrator": En lugar de una foto tuya gigante, coloca una visualización abstracta de una "Arquitectura de Contexto Modular". Un núcleo central que se ramifica hacia archivos .md flotantes (Agents.md, Skills.md). El texto central: "Architecting systems where AI is the Gold Standard of Quality".
The Project Terminals: Los proyectos (AINativeNav, Hospital Monte España, SaaS Contable) no deben estar en tarjetas simples. Deben aparecer como "Módulos de Código". Cada proyecto tiene un encabezado tipo pestaña de editor de código con su stack tecnológico visible en el borde inferior (ej. .net8, react19, docker).
The Skills Canvas: Presenta tus habilidades como un "Grafo de Dependencias". No uses barras de porcentaje. Usa nodos interconectados donde los núcleos sean AIDD, Enterprise Backend y Modern Web.
Interactive Footer / Gemini CLI: Una terminal funcional al final de la página donde el usuario pueda escribir comandos. Si el usuario escribe octavio --contact, la terminal debe imprimir tu email y LinkedIn con un efecto de máquina de escribir.
Instrucciones de Estilo:
Tipografía: Inter para el cuerpo (legibilidad) y JetBrains Mono para los detalles técnicos y números.
Animaciones: Nada de rebotes infantiles. Usa transiciones lineales y rápidas (0.2s) que den sensación de rendimiento extremo.
Coherencia de Marca: Refleja el orden y la limpieza de tus rutinas (vibe CeraVe/Cetaphil): mucho aire entre elementos, bordes definidos y cero desorden visual.
Genera un solo diseño SPA con todo lo antes mencionado.
```
